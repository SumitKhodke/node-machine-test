# Node JS Machine Test

## Tech Stack
- Node.js
- Express.js
- MySQL (RDBMS)
- EJS View Engine

## Features
- Category CRUD
- Product CRUD
- Product belongs to Category
- Server-side pagination using LIMIT and OFFSET

## How to Run
1. Create MySQL database and tables
2. Update db.js credentials
3. Run:
   npm install
   npm start
4. Open browser:
   http://localhost:3000
